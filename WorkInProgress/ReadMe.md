# 💰 Criando uma Ferramenta de Controle de Investimentos com Excel

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio da DIO "Criando uma Ferramenta de Controle de Investimentos com Excel".

O objetivo é construir uma planilha capaz de auxiliar investidores na simulação de investimentos em Fundos Imobiliários (FIIs), permitindo analisar diferentes cenários e compreender o impacto dos aportes mensais ao longo do tempo.

------

## 🎯 Objetivos

- Simular investimentos em FIIs
- Calcular patrimônio acumulado
- Projetar dividendos mensais
- Comparar cenários de investimento
- Aplicar recursos avançados do Excel
- Criar uma ferramenta prática para tomada de decisão

------

## 🛠️ Tecnologias Utilizadas

- Microsoft Excel
- Fórmulas Financeiras
- Validação de Dados
- Formatação Condicional
- Nomes de Intervalos
- Simulação de Cenários

## 📊 Funcionalidades

### Simulador de Patrimônio

Permite informar:

- Valor inicial
- Aporte mensal
- Prazo de investimento
- Taxa de rendimento mensal

Retornando:

- Valor total investido
- Patrimônio acumulado
- Rentabilidade obtida

------

### Simulador de Dividendos

Permite visualizar:

- Patrimônio projetado
- Dividend Yield
- Dividendos mensais estimados

------

### Simulador de Cenários

Comparação entre:

- Cenário Conservador
- Cenário Moderado
- Cenário Agressivo
